Community Events App

This app brings people people together through local and paid community events.

Description

 Community Events is an iOS app written using swiftUI that allows users to view and create events. These events are based on the users city, which is gained through location services. 
 These local events are posted to the home page with the event details, time, date, location, selectable image, language, and age groups. Users can filter out events based on these event specifiers.
 Events for the users city are also fetched and displayed from the TicketMaster API, offering some paid events, with links to the website to book the tickets.
 The goal of the app is to bring people together and find their communities. The app also offers a map view to see the users location and the events happening around them.
